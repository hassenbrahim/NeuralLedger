# NeuralLedger

Serves blockchain developers with a decentralized and secure data management platform for tracking and auditing cryptocurrency transactions.

NeuralLedger is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/NeuralLedger.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NeuralLedger is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
